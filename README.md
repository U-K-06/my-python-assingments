# Student Grade Analyzer

## Overview

**Student Grade Analyzer**(SGA) is a **python program** which can take existing student data from a **CSV** file or make a new CSV file to store student's marks records. The Program can calculate the average of
and assign grades to a student based on their marks and can even visualise thier marks using **matplotlib** and **graphs**.

## Flexibility 

The program is **not** really flexible as it requires data to be in a **very specefic format** for it to work and the visualization created is basic at best with the lack of **GUI** making it less attractive
for casual users.

## Dependacies

The program requires the following python libraries to work:

- Numpy
- Pandas
- Matplotlib

### NOTE: You also require a **python interpretor** to run the program
